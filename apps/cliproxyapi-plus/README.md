# CLIProxyAPI Plus

CLIProxyAPI Plus 代理API服务，基于主线项目添加第三方提供商支持。

## 功能特点

- 支持多种代理协议
- 支持第三方提供商
- 高性能设计
- 易于部署和使用

## 使用说明

### 默认端口

- Web 界面: 8317
- API 端口: 8085
- 其他端口: 1455, 54545, 51121, 11451

### 数据目录

应用数据存储在 `./data` 目录，包含：
- `config.yaml` - 配置文件
- `auths/` - 认证信息目录
- `logs/` - 日志目录
